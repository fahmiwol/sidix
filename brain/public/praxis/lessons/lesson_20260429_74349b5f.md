```python
def kalkulator():
    # Meminta input dari pengguna
    print("Selamat datang di Aplikasi Kalkulator Sederhana!")
    num1 = float(input("Masukkan angka pertama: "))
    num2 = float(input("Masukkan angka kedua: "))

    # Menampilkan pilihan operasi yang dapat dilakukan
    print("\nPilih operasi:")
    print("1. Penjumlahan (+)")
    print("2. Pengurangan (-)")
    print("3. Perkalian (*)")
    print("4. Pembagian (/)")

    # Meminta input pilihan operasi
    choice = input("Masukkan pilihan (1/2/3/4): ")

    result = None

    if choice == '1':
        result = num1 + num2
        operation = "penjumlahan"
    elif choice == '2':
        result = num1 - num2
        operation = "pengurangan"
    elif choice == '3':
        result = num1 * num2
        operation = "perkalian"
    elif choice == '4':
        if num2 != 0:
            result = num1 / num2
            operation = "pembagian"
        else:
            return "Tidak bisa membagi dengan nol!"

    # Menampilkan hasil
    print(f"Hasil dari {num1} {operation} {num2} adalah: {result}")

# Memanggil fungsi kalkulator
kalkulator()
```

- Membuat aplikasi yang mengambil dua input angka dari pengguna.
- Menampilkan pilihan operasi dasar.
- Melakukan perhitungan berdasarkan pilihan pengguna.
- Menampilkan hasil akhir.
