### Contoh Sederhana

Misalkan kita memiliki sebuah program yang mencetak angka dari 1 hingga 10 menggunakan dua thread:

```python
import threading
import time

# Variabel共享数据可能导致竞争条件。
counter = 0

def increment_counter():
    global counter
    for _ in range(5):
        # 模拟耗时操作
        time.sleep(0.1)
        counter += 1
        print(f"Thread {threading.current_thread().name}: Counter is now {counter}")

# 创建两个线程
t1 = threading.Thread(target=increment_counter, name="Thread-1")
t2 = threading.Thread(target=increment_counter, name="Thread-2")

# 启动线程
t1.start()
t2.start()

# 等待所有线程完成
t1.join()
t2.join()

print(f"Final counter: {counter}")
```

当你运行这段代码，结果可能会不一致。例如，最终的计数器值可能不是10，因为两个线程同时更新 `counter` 变量。
