- **Final (cuplikan):** [FAKTA] Perbedaan utama antara `let` dan `const` dalam JavaScript terletak pada fleksibilitas penggunaannya dalam menentukan variabel.

1. **let**:
   - Memungkinkan deklarasi variabel dengan blok scope, yang berarti variabel dapat diubah nilainya.
   - Contoh kode:
     ```javascript
     let x = 10;
     x = 20; // Valid: mengubah nilai x dari 10 menjadi 20
     ```

2. **const**:
   - Biasanya digunakan untuk deklarasi variabel dengan blok scope, namun nilainya tidak dapat diubah setelah deklarasi.
   - Contoh kode:
     ```javascript
     const y = 10;
     // y = 20; // Invalid: mencoba mengubah nilai y akan menyebabkan error
     ```

Jadi, `let` memungkinkan penugasan ulang nilai variabel, sementara `const` tidak. Penggunaan `const` sebaiknya digunakan ketika nilai dari variabel sudah pasti dan tidak perlu diubah.

Dalam praktiknya, pemilihan antara `let` dan `const` tergantung pada kebutuhan spesifik projek atau logika kode Anda. Misalnya, jika variabel hanya akan digunakan sebanyak satu kali dalam blok tertentu, lebih baik menggunakan `const`.
