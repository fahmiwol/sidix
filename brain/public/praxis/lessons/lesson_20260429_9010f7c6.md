```python
def is_prime(n):
    """Fungsi untuk mengecek apakah suatu bilangan n adalah bilangan prima."""
    
    # Bilangan prima lebih besar dari 1
    if n <= 1:
        return False
    
    # Cek pembagi hingga akar kuadrat n
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

# Contoh penggunaan fungsi
bilangan = 29
if is_prime(bilangan):
    print(f"{bilangan} adalah bilangan prima.")
else:
    print(f"{bilangan} bukan bilangan prima.")
```

Penjelasan kode:
1. Fungsi `is_prime(n)` menerima parameter `n` yang akan diperiksa.
2. Bilangan primer lebih besar dari 1, jadi pertama-tama kita cek apakah `n` kurang dari atau sama dengan 1.
3. Kita mengiterasi melalui semua bilangan bulat dari 2 hingga akar kuadrat `n`. Jika `n` habis dibagi salah satu dari mereka, maka `n` bukan bilangan prima.
4. Jika tidak ada pembagi selain 1 dan `n` itu sendiri, maka `n` adalah bilangan prima.
