def is_prime(n):
    """Fungsi yang mengembalikan True jika n adalah bilangan prima, False jika tidak."""
    
    # Bilangan prima lebih besar dari 1
    if n <= 1:
        return False
    
    # Cek faktor hingga akar kuadrat dari n
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
            
    return True

# Contoh penggunaan fungsi
print(is_prime(7))   # Output: True
print(is_prime(10))  # Output: False
```

Penjelasan singkat:
1. Fungsi `is_prime(n)` memeriksa apakah bilangan `n` adalah prima.
2. Jika `n` kurang dari atau sama dengan 1, langsung dikembalikan `False`.
3. Untuk bilangan lainnya, kita cek faktornya hingga akar kuadrat `n`. Jika ada faktor yang dapat membagi `n`, maka `n` bukan bilangan prima.

Contoh penggunaan fungsi tersebut telah diberikan di bagian bawah kode.
