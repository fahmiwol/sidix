```python
def is_prime(n):
    """Memeriksa apakah bilangan n adalah bilangan prima."""
    
    # Bilangan kurang dari 2 bukan bilangan prima
    if n <= 1:
        return False
    
    # Cek pembagi dari 2 hingga akar kuadrat dari n
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
            
    return True

# Contoh penggunaan fungsi
print(is_prime(7))  # Output: True
print(is_prime(10)) # Output: False
```

Fungsi `is_prime` ini melakukan pengecekan dengan cara memeriksa adanya pembagi dari bilangan yang lebih kecil atau sama dengan akar kuadrat dari n. Ini efektif karena jika n bukan prima, pasti ada faktornya di antara 2 dan √n.

Pada contoh penggunaan, fungsi dipanggil untuk beberapa nilai untuk memeriksa apakah mereka adalah bilangan prima atau tidak.
