### Langkah 2

- **Thought:** Sudah ada hasil Wikipedia. Rangkai final answer dengan label sumber web.
- **Final (cuplikan):** **Attention Mechanism** (Vaswani et al., 'Attention is All You Need', 2017) — mekanisme di Transformer yang menghitung relevance antar token via Query (Q), Key (K), dan Value (V) matrices. Formula: `Attention(Q,K,V) = softmax(QK^T/√d_k)·V`. Setiap token 'attend' ke token lain dengan bobot dinamis. Self-attention = Q,K,V dari sequence yang sama. Multi-head attention = paralel attention dengan beda projeksi → tangkap pola berbeda secara simultan.
