## Jawaban akhir (ringkas)

[FAKTA] Perbedaan utama antara `let` dan `const` di JavaScript terletak pada visibilitas dan mutability variabelnya. Mari kita bahas detailnya:

1. **Mutability (Ubahan)**
   - `let`: Variabel yang didefinisikan dengan kata kunci `let` dapat diubah nilai-nya setelah deklarasi.
     ```javascript
     let x = 5;
     x = 10; // Ini valid, nilai x berubah menjadi 10.
     ```
   - `const`: Variabel yang didefinisikan dengan kata kunci `const` harus diinisialisasi saat deklarasi dan nilainya tidak dapat diubah setelahnya. Jika Anda mencoba mengubah nilai `const`, akan muncul error.
     ```javascript
     const y = 10;
     y = 20; // Ini akan menghasilkan kesalahan, karena nilai y tidak bisa diubah.
     ```

2. **Visibilitas (Kemampuan untuk Diakses)**
   - Kedua kata kunci `let` dan `const` mendefinisikan blok scope. Artinya, variabel yang didefinisikan dengan `let` atau `const` hanya dapat diakses dalam blok kode dimana mereka dibuat.
     ```javascript
     if (true) {
       let z = 10; // Variabel z hanya bisa diakses dalam blok ini
     }
     console.log(z); // Ini akan menghasilkan kesalahan, karena z tidak didefinisikan secara global.
     ```

3. **Initial Assignment**
   - `let`: Dapat digunakan tanpa inisialisasi, meskipun biasanya lebih baik untuk memberi nilai saat deklarasi.
     ```javascript
     let a; // Valid, tetapi biasanya lebih baik memberi nilai saat deklarasi: let b = 5;
     ```
