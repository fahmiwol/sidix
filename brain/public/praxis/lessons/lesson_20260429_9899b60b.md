def is_prime(n):
    """Fungsi yang mengembalikan True jika n adalah bilangan prima, False jika bukan."""
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

# Contoh penggunaan fungsi
bilangan = 29
if is_prime(bilangan):
    print(f"{bilangan} adalah bilangan prima.")
else:
    print(f"{bilangan} bukan bilangan prima.")
```

Fungsi `is_prime(n)` ini bekerja dengan cara menguji apakah ada faktor lain selain 1 dan dirinya sendiri untuk setiap bilangan dari 2 hingga akar kuadrat dari `n`. Jika ditemukan, maka `n` bukan bilangan prima.
