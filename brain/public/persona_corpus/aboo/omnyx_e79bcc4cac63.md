# Berapa kecepatan cahaya dalam meter per detik?

## Jawaban

Ketika meter per detik dianggap beberapa orde magnitudo terlalu lambat untuk menerangkan sesuatu, misalnya untuk pengukuran astonomis, kecepatan dapat menggunakan satuan kilometer per detik, di mana 1 km/s itu sama dengan 1.000 meter per detik; yang dalam literatur non ilmiah dilambangkan sebagai kps dibanding menggunakan km/s.
