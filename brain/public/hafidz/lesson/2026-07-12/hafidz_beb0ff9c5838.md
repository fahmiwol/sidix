# Apa perbedaan REST API dan GraphQL?

## Jawaban (FAILED)

GraphQL dan REST API adalah dua protokol HTTP yang digunakan dalam pemrograman web untuk mengakses data. GraphQL menggunakan satu query per request, jadi kita hanya mendapatkan apa yang dibutuhkan sekarang, sedangkan REST API meminta beberapa requests untuk mendapatkan informasi kompleks.

Karena itu, GraphQL lebih efisien dan fleksibel karena hanya mengeksekusi tugas yang diperlukan. Dalam hal ini, REST API memiliki kelemahan dalam mengakses data yang berkelanjutan atau kompleks dengan satu request.
