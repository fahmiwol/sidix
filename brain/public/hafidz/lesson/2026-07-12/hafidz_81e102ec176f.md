**Apa perbedaan let dan const di JavaScript?**

Ketika kita mempelajari variabel di JavaScript, ada beberapa istilah yang sering digunakan: var, let, dan const. Setiap kata kunci ini memiliki peran unik dalam pemrograman.

1. **var**: 
   - Kode: `let` atau `const`
   - Contoh:
     ```javascript
     let exampleVar = 5; // variabel yang dapat diubah
     ```
   - FAKTA GROUNDING: var adalah kata kunci JavaScript yang digunakan untuk mendeklarasikan variabel. Dalam JavaScript, var memiliki scope global (tidak tertentu) dan mutabilitas (variabel bisa diperbarui).

2. **let**: 
   - Kode: `let` atau `const`
   - Contoh:
     ```javascript
     let exampleLet = 5; // variabel yang dapat diubah, tetapi jika kita pernah mendeklarasikannya sebelumnya, tidak bisa lagi dipindahkan ke lokasi lain.
     ```
   - FAKTA GROUNDING: Let adalah kata kunci JavaScript yang digunakan untuk mendeklarasikan variable. Dalam JavaScript, let memiliki scope local (dapat berada dalam blok, statement, dll) dan mutabilitas (variabel tidak bisa diperbarui).

3. **const**: 
   - Kode: `let` atau `const`
   - Contoh:
     ```javascript
     const exampleConst = 5; // variabel yang tetap dan tidak dapat diubah.
     ```
   - FAKTA GROUNDING: Const adalah kata kunci JavaScript yang digunakan untuk mendeklarasikan variable. Dalam JavaScript, const memiliki scope global (tidak tertentu) dan mutabilitas (variabel tidak bisa diperbarui).

Secara keseluruhan, let dan const memiliki peran yang beragam dalam JavaScript. Sementara itu, const adalah untuk variable yang stabil dan tidak bisa dirubah, meskipun kita pernah mendeklarasikannya sebelumnya.
