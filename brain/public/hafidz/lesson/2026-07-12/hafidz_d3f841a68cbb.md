# Apa perbedaan REST API dan GraphQL?

## Jawaban (FAILED)

REST API dan GraphQL adalah dua metode yang umum digunakan untuk mengambil data dari server ke aplikasi, tetapi memiliki beberapa perbedaan utama. REST (Representational State Transfer) API menggunakan HTTP methods seperti GET, POST, PUT, DELETE untuk mengakses sumber daya berbasis resource. Sementara itu, GraphQL adalah framework yang memungkinkan client menentukan data yang dibutuhkan dalam satu permintaan dan mendapatkan hanya apa yang mereka minta.
