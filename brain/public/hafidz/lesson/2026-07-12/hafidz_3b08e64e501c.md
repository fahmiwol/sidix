# Apa perbedaan REST API dan GraphQL?

## Jawaban (FAILED)

GraphQL dan REST API adalah dua teknologi yang digunakan dalam pembuatan API untuk aplikasi web. 

GraphQL:
- Digunakan sebagai solusi alternatif untuk kebutuhan penggunaan data yang lebih detail, jadi bisa mencapai performance optimal.
- Dengan GraphQL, kita dapat mengakses data secara langsung dan berdasarkan permintaan spesifik. Jadi kita tidak perlu menunggu seluruh database dipanggil.

REST API:
- Digunakan sebagai solusi standar saat ini, dengan konsep "get everything you want." (Hargai apa yang kamu butuhkan).
- REST API memang lebih mudah dan cepat untuk implementasi dan pemrograman. Jadi ini adalah pilihan ideal jika kita hanya membutuhkan data dasarnya.

Berdasarkan arsitektur data, GraphQL biasanya digunakan di aplikasi web dengan data yang kompleks atau berantakan, sementara REST API lebih cocok untuk aplikasi lainnya seperti administrasi dan sistem keuangan. Jadi, ini adalah kesimpulan dari pertanyaan Anda: **GraphQL memang lebih baik untuk aplikasi web yang memiliki data yang detail dan kompleks, sedangkan REST API sebaiknya dipakai di aplikasi lain yang hanya butuh data dasar dan mudah digunakan**.
