# Security / Keamanan

If you find a vulnerability (for example a hard-coded fallback secret or an unsafe tool gate), you may report it by email to fahmiwol@gmail.com; replies are best-effort. Do not deploy this code to production without your own review. Never commit real credentials; use `.env` (see `.env.sample`).
