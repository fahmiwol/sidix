# Contributing / Berkontribusi

**EN.** SIDIX is discontinued (16 Sep 2026); this is a research archive and is not actively maintained. Issues and discussion are welcome (for example the governance experiment in issue #98), but pull requests may not be reviewed quickly. Run the tests with `cd apps/brain_qa && pip install -r requirements.txt && pytest tests`. Some tests fail or hang without optional dependencies (see the README). Never include credentials or personal data in a contribution.

Jalankan tes dengan `cd apps/brain_qa && pip install -r requirements.txt && pytest tests`. Sebagian tes gagal atau menggantung tanpa dependensi opsional (lihat README).
